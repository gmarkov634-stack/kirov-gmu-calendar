# Parser rules

Здесь хранятся КГМУ-специфичные правила интерпретации официального расписания. Правила должны быть версионируемыми и приводить результат к v1 NormalizedEvent/ParsingResult из medical-calendar-core.

Текущий bundle описан в `v1/manifest.json`. Канонические тексты правил ведутся в проектной папке Google Drive и разделены на слои:

- G — общие правила для поддерживаемых XLSX КГМУ;
- R — недельные расписания, P — postprocessing после нормализации;
- C — цикловые расписания старших курсов;
- S — смешанные недельно-цикловые расписания.

Приоритет: явные данные текущего XLSX → специальный профиль R/C/S → общий слой G → ручная проверка. Любая неоднозначность, не разрешаемая однозначно этими данными и правилами, получает `REVIEW_REQUIRED`, требует подтверждения пользователя и блокирует публикацию. Догадывание и молчаливое отбрасывание содержательных ячеек запрещены.
