# Faculty/group catalog

Каталог КГМУ охватывает только проектовый scope: лечебное дело, педиатрию и стоматологию.

Каждый учебный год и семестр хранится отдельным snapshot-файлом по шаблону `YYYY-YYYY-semester-N.json`. Старые snapshots не перезаписываются: это позволяет поддерживать 2026/27, 2027/28 и последующие годы без изменения shared core и сохранять историю опубликованной структуры групп.

Факультеты, курсы и группы добавляются только после проверки официального источника. Идентификаторы должны быть стабильными и соответствовать shared contracts core.
