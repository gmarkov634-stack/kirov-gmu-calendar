# Medical university calendars

Сайт электронного расписания и календарей студентов медицинских вузов.

## Точки входа

- `index.html` — действующий сайт Кировского ГМУ;
- `omgmu.html` — предварительный интерфейс ОмГМУ;
- `data.js` — конфигурация КГМУ;
- `universities/omgmu.js` — конфигурация ОмГМУ.

Общая клиентская логика находится в `app.js`, а адаптация названия, оформления, платёжного запроса и разделения сохранённых покупок по вузам — в `platform.js`.

Поле `offer.checkoutEnabled` отражает готовность конкретного вуза принимать платежи. Для КГМУ оно включено, для ОмГМУ — выключено до появления серверного разделения расписаний и реальных групп.
