# Medical university calendars

Сайт электронного расписания и календарей студентов медицинских вузов.

## Точки входа

- `index.html` — действующий сайт Кировского ГМУ;
- `omgmu.html` — предварительный интерфейс ОмГМУ;
- `data.js` — конфигурация КГМУ;
- `universities/omgmu.js` — конфигурация ОмГМУ.

Общая клиентская логика находится в `app.js`, а адаптация названия, оформления, платёжного запроса и разделения сохранённых покупок по вузам — в `platform.js`.

Поле `offer.checkoutEnabled` отражает готовность конкретного вуза принимать платежи. Для КГМУ оно включено, для ОмГМУ — выключено до появления серверного разделения расписаний и реальных групп.

## Архитектура импорта

Вузовские правила изолируются в `api/src/adapters/{university}`. Сейчас добавлен адаптер обнаружения источников ОмГМУ:

- `api/src/adapters/omgmu/discover.mjs` — чтение официальной страницы и классификация файлов;
- `api/tools/omgmu-discover.mjs` — совместимая CLI-команда;
- `api/src/import/normalized-schedule.js` — общий контракт, который должны выдавать адаптеры ОмГМУ, ПГМУ и следующих вузов.

Нормализованное расписание содержит `university`, `program`, `course`, необязательный `stream`, произвольный `group.code`, часовой пояс, источники и массив событий. Оплата, хранение подписок и генерация ICS не должны содержать условий, специфичных для конкретного вуза.

Для ПГМУ должен быть добавлен отдельный каталог `api/src/adapters/pgmu`, но его результат обязан проходить тот же валидатор нормализованного расписания.

Запуск обнаружения источников ОмГМУ:

```bash
cd api
npm run discover:omgmu
```
