## Правила публикаций и изменений

- Перед каждой новой публикацией сначала показать пользователю полный черновик в чате. Публиковать только после явного подтверждения пользователя.
- Перед изменением информации сообщества сначала показать точный diff «было → станет». Применять только явно подтверждённые поля и значения.
- Не сообщать, что расписание текущего учебного периода доступно, пока соответствующая группа не прошла source-bound review, canonical QA и фактическую публикацию.
- Не помещать изменяемую цену в вечнозелёный закреп, описание сообщества или образовательные публикации; коммерческие условия должны браться из актуального оффера сайта.
- Новые текстовые посты можно публиковать через защищённый GitHub OIDC control plane с `wall.post`.
- `group.info` разрешён как read-only команда; mutation-команда для метаданных сообщества до отдельного approval/implementation отсутствует.
- Закрепление и удаление существующих постов при текущих токенах остаются ручными действиями VK.
- Operational PR с `ops/vk/command.json` всегда закрывается без merge после выполнения команды.
