# Source configuration

Официальные источники КГМУ добавляются только после проверки на официальном сайте/сервере. Production secrets не допускаются.

Проектовый scope КГМУ ограничен тремя направлениями: лечебное дело, педиатрия и стоматология.

`source/sources.json` хранит стабильные страницы discovery и правила поиска XLSX, а не конфигурацию одного конкретного учебного года. Новый учебный год не требует изменения shared core: после проверки официальной публикации создаётся новый versioned catalog snapshot для соответствующего `academicYear` и `term`.
