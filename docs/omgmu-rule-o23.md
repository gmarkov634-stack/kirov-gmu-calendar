# ОмГМУ — правило O23

## O23. Номер цикла как структурный атрибут

Метки вида `1 цикл`, `2 цикл`, `3 цикл` и т. п. являются структурными заголовками блока циклового расписания и не входят в название дисциплины или пользовательское название события.

Номер цикла сохраняется в техническом `source_cycle_no`/`evidence` для трассировки и проверки исходника. Сам по себе номер цикла не определяет группу, даты или тип события — эти данные берутся из соответствующих ячеек блока.

Подтверждено по реальному официальному PDF ОмГМУ `4zan.pdf`: на русской странице отдельными заголовками таблицы указаны `1 цикл: 07.05–31.07` и `2 цикл: 29.05–30.07`, после чего следуют дисциплины, время, `К.дн.` и групповые колонки 485/486.
