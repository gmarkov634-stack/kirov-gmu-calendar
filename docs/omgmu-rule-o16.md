# ОмГМУ — правило O16

## O16 — Геометрическая принадлежность объединённой ячейки группам

Если одна ячейка PDF визуально охватывает несколько колонок групп, её содержимое относится ко всем этим группам.

Принадлежность определяется по реальной геометрии исходного PDF: линиям таблицы, границам групповых колонок и фактическому span объединённой/растянутой ячейки. Горизонтальная позиция текста после `pdftotext -layout`, OCR или другого извлечения текста не является самостоятельным доказательством того, что запись относится только к ближайшему номеру группы.

Порядок разбора:

1. определить групповые колонки по заголовкам и границам таблицы;
2. определить фактические границы конкретной ячейки/объединённой области;
3. установить, какие групповые колонки она геометрически охватывает;
4. назначить содержимое всем охваченным группам;
5. только после этого разбирать время, дисциплину, даты и другие поля.

Нельзя сдвигать принадлежность события на соседнюю группу только потому, что текст внутри merged cell визуально выровнен ближе к одной стороне или после извлечения layout-текста оказался под соседним номером.

Если границы ячейки неоднозначны либо извлечённый layout-текст противоречит визуальной геометрии и конфликт нельзя однозначно разрешить по исходному PDF, блок получает `needs_review`.

## Подтверждённый пример

`1.2.pdf`, русская часть, понедельник, группы 1107–1112:

- «Ин. язык (рус. язык)» — объединённая область групп 1107–1108;
- «Гистология, эмбриология, цитология» — объединённая область групп 1109–1110;
- следующий «Ин. язык (рус. язык)» — объединённая область групп 1111–1112.

Следовательно, средний блок нельзя относить к группе 1108 только из-за положения текста после `pdftotext -layout`.

## Область применения

O16 действует в профилях, где принадлежность события к нескольким группам определяется геометрией объединённых/растянутых ячеек. Текущая область применимости правила не меняется этим уточнением.
