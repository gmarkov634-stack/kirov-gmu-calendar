# ОмГМУ — правило O54

## O54 — Академические периоды из шапки PDF являются source metadata, а не событиями

Если строки верхнего уровня документа явно описывают академические периоды (`Classes`, `Examination session`, `Educational practice`, `Industrial practice`, `Holidays`, `Auditorium classes` и их русские эквиваленты), они распознаются как `source_periods`.

Такие строки:
- не создают календарные события;
- не становятся дисциплинами;
- не попадают в пользовательские названия;
- сохраняются в `evidence`/source metadata вместе с исходной формулировкой и диапазоном;
- могут использоваться как контрольные границы для учебных серий соответствующего типа.

Подтверждённый `Classes`/`Auditorium classes` является контрольным envelope для обычных учебных серий соответствующего типа. Необъяснимый выход обычного занятия за такой период переводит серию в `needs_review`.

`Examination session`, учебная/производственная практика и каникулы сами по себе не создают события расписания занятий. Для их отображения в пользовательском календаре требуется отдельный подтверждённый источник или отдельное правило.

Явная строка `Public holidays`/«Праздничные дни» обрабатывается как `calendar_exceptions` по O33, а не как обычный `source_period`.

### Область применимости

O54 является общим правилом и применяется ко всем четырём текущим production-профилям ОмГМУ:
- `weekly_grid`;
- `course_lecture_list`;
- `cycle_rotation_grid`;
- `combined_rotation_table`.
