# ОмГМУ — правило O60

## O60 — Сноска о перерывах является source-level timing metadata

Область применения: только `weekly_grid`.

Если звёздочка расположена у заголовка расписания и в том же `source_part` имеется соответствующая сноска `*В расписании занятий предусмотрены перерывы` / `*Class schedule includes breaks`, эта пара распознаётся как служебная metadata уровня источника, например `schedule_includes_breaks = true`.

Такая звёздочка:

- не является частью названия документа или дисциплины;
- не создаёт событие;
- не задаёт особую дату;
- не трактуется по O31.

Явно указанный в строке единый временной интервал сохраняется буквально от начала до конца по O50, даже если внутри него предусмотрены перерывы. Сноска сама по себе не даёт права вычислять, вычитать, добавлять или реконструировать внутренние интервалы. Если источник самостоятельно перечисляет несколько source time slots, они обрабатываются по соответствующим правилам.

Значение `*` определяется по локальному контексту:

- `РАСПИСАНИЕ*` вместе со сноской о перерывах → O60;
- `*08.20–10.00 ...` в подтверждённой структуре `course_lecture_list` → O31.

Одинаковый символ `*` нельзя глобально наделять одним значением для всего PDF.

## Подтверждённый паттерн

Во всех пяти текущих PDF профиля `weekly_grid` используется заголовок вида `РАСПИСАНИЕ УЧЕБНЫХ ЗАНЯТИЙ*` / `SHEDULE OF CLASSES*` и нижняя сноска `*В расписании занятий предусмотрены перерывы` / `*Class schedule includes breaks`.
