# КГМУ — покрытие типов XLSX

## Шаг 1. Довести до конца парсинг всех типов XLSX КГМУ

Статус: **в работе**.

Цель шага — подтвердить покрытие всех реально встречающихся структур официальных XLSX Кировского ГМУ. Отдельный парсер не создаётся для каждого курса автоматически: новый профиль нужен только тогда, когда новый исходник содержит структурный паттерн, который нельзя однозначно разобрать существующими правилами.

## Подтверждённые профили

- `R` — типовое недельное расписание.
- профиль педиатрических R-паттернов, проверенный на 1–2 курсах.
- лечебный R-профиль 3 курса.
- `C` — цикловое расписание.
- `R-FIO` — недельное расписание младших курсов факультета иностранных обучающихся.
- `C-FIO` — старшие курсы ФИО.
- `S` — смешанное недельно-цикловое расписание.

## Критерий завершения шага 1

Шаг закрывается после аудита остальных официальных XLSX и подтверждения, что каждый обнаруженный структурный тип либо покрывается существующим профилем, либо получил отдельные подтверждённые правила и regression-проверку.

После закрытия шага выполняется dependency-review шагов 2–12. Уже завершённые архитектурные шаги не переписываются без необходимости; изменения вносятся только при появлении нового канонического требования.
