# ОмГМУ — правило O65

## O65 — Последовательные экземпляры одной дисциплины в `weekly_grid` могут объединяться после независимого разбора source-series

Область применения: только `weekly_grid`.

Каждая геометрически самостоятельная запись недельной таблицы сначала разбирается как отдельная `source_series` со своими:

- `time`;
- `date_expression`;
- `source_counter`;
- геометрическим anchor;
- `raw_source/evidence`.

Разворачивание дат и проверка явных счётчиков выполняются для каждой source-series независимо. Объединение для пользовательского календаря не имеет права менять результат этой проверки, подменять отдельные счётчики общим числом или превращать два исходных диапазона в один.

После независимого разбора, если для одной группы на одну календарную дату несколько source-series дают последовательные по времени занятия одной и той же нормализованной дисциплины, между ними нет другого занятия и их порядок однозначен, эти экземпляры разрешается представить в итоговом пользовательском календаре одним событием от начала первого до окончания последнего.

Короткий перерыв между интервалами сам по себе не препятствует объединению. Объединение выполняется только на уровне итогового пользовательского события; исходные source-series и все их evidence сохраняются раздельно.

Автоматическое объединение запрещено, если:

- нормализованные дисциплины различаются;
- принадлежность одной из серий группе неоднозначна;
- временной порядок неоднозначен или интервалы конфликтуют;
- между интервалами находится другое занятие этой группы;
- объединение меняет смысл явно указанного типа занятия;
- одна из исходных серий не прошла собственную обязательную валидацию.

## Подтверждённый пример

`1.2.pdf`, понедельник, группы 1109–1110:

- `13:30–15:55 — Гистология, эмбриология, цитология, 18 зан.: 06.04–03.08`;
- `16:00–18:25 — Гистология, эмбриология, цитология, 1 зан.: 20.07`.

Обе source-series сначала разбираются и валидируются независимо. На дате `20.07` они дают два последовательных экземпляра одной дисциплины, поэтому итоговый пользовательский календарь может содержать одно событие:

`13:30–18:25 — Гистология, эмбриология, цитология`.

Evidence обеих исходных серий при этом сохраняется.

## Связь с O19

O65 является weekly-аналогом идеи объединения, но не расширяет область O19. O19 остаётся подтверждённым только для `cycle_rotation_grid`, где объединяются последовательные source time slots внутри одного циклового учебного блока. Для `course_lecture_list` и `combined_rotation_table` автоматическая применимость O19/O65 не предполагается без отдельного подтверждения.
