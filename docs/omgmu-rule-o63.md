# ОмГМУ — правило O63

## O63 — Набор учебных дней weekly_grid определяется самим источником, а не правилом Пн–Пт

В профиле `weekly_grid` каждый явно обозначенный weekday-блок (`Понедельник` … `Суббота` / `Monday` … `Saturday`) является самостоятельным структурным днём расписания.

Если серия находится в блоке `Saturday` / `Суббота`, её диапазон по O04 разворачивается по субботам так же, как диапазон понедельника разворачивается по понедельникам. К `weekly_grid` запрещено применять глобальное предположение `учебные дни = Пн–Пт` и автоматически исключать субботы.

Наличие субботних занятий в одном `source_part` не означает, что все субботы семестра учебные: создаются только даты конкретных серий. Явные `calendar_exceptions` и более конкретные указания источника сохраняют приоритет.

Воскресенье не добавляется автоматически только потому, что источник использует шестидневную неделю. Правила непрерывных циклов O07/O32 не переносятся на недельную таблицу.

Если новый weekly-источник содержит другой набор weekday-блоков, parser следует его явной структуре, а не жёстко заданному набору рабочих дней.

## Подтверждённый пример

В текущем `3.pdf` в блоке `Saturday` / `Суббота` присутствует серия:

`08.00–10.25 Pathophysiology, 16 cl.: 11.04–01.08`

Её диапазон разворачивается именно по субботам внутри указанных границ.

## Область применения

Только `weekly_grid`.
