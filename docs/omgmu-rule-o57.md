# ОмГМУ — правило O57

## O57 — Количество занятий в недельной серии является контрольным признаком, а не источником дат

Область применения: только `weekly_grid`.

Если в `weekly_grid` для одной дисциплинарной серии явно указано количество занятий (`N зан.`, `N занятий` или однозначный эквивалент), это число используется для контроля результата, но не для генерации дат.

Даты сначала определяются независимо из более конкретных данных русского источника: `group + weekday + диапазон/перечень дат + подтверждённые calendar exceptions` по O03–O04 и другим применимым правилам.

Если полученное число дат совпадает с N, контроль пройден.

Если не совпадает, парсер не подгоняет расписание под N: запрещено добавлять недостающие даты, расширять диапазон, менять weekday или удалять даты только ради совпадения счётчика. Расхождение фиксируется в parser/QA, после чего проверяется, можно ли однозначно доказать опечатку именно в N по независимым данным русскоязычного официального источника.

Автоматически признать N опечаткой допустимо только при единственной доказуемой интерпретации, например когда:

- явный перечень дат содержит другое точное количество;
- диапазон + конкретный weekday дают единственный возможный набор дат;
- другой официальный русскоязычный источник подтверждает это же количество.

Если такого доказательства нет, серия получает `needs_review`.

Специальные случаи сохраняют приоритет своих правил: для явного `N лекций` применяется O27, для парного счётчика `X/Y` — O13. O57 развивает принцип доказуемой коррекции O15 и не разрешает арифметически подгонять расписание под контрольное число.

Подтверждённый пример: группа 1102, вторник, «Ин. язык (рус. язык)». Русская запись содержит `5 зан.: 07.04–14.07`, однако сам диапазон содержит 15 вторников. Поэтому значение 5 является доказуемой технической опечаткой счётчика; английская часть по O64 для этого вывода не используется.
