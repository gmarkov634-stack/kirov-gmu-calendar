# ОмГМУ — правило O61

## O61 — Составное выражение дат разбирается как объединение независимых компонентов

Если в `weekly_grid` или в строке `course_lecture_list`, находящейся внутри подтверждённого weekday-блока, поле дат одной серии содержит несколько компонентов, разделённых `,` или `;`, и каждый компонент однозначно является либо одиночной датой `dd.mm`, либо диапазоном `dd.mm–dd.mm`, компоненты сначала разбираются независимо, а затем объединяются в единый набор дат серии.

Одиночная дата используется буквально. Диапазон разворачивается только на соответствующий structural weekday по O04. Одиночная дата дополнительно проверяется на соответствие structural weekday; необъяснимое расхождение переводит серию в `needs_review`.

Если одна дата получается из нескольких компонентов, создаётся одно событие. После объединения выполняется проверка явного количества занятий по O27/O57.

Запрещено превращать составное выражение вроде `07.04, 21.04–02.06` в единый диапазон `07.04–02.06`, поскольку это создало бы даты, отсутствующие в источнике.

До разбора компонентов граница полного date expression отделяется от `location` по O58. Например, в записи `07.04, 21.04–02.06, АЗ ГК` первые два компонента относятся к датам, а `АЗ ГК` — к месту проведения.

O61 применяется только к профилям:

- `weekly_grid`;
- `course_lecture_list`.

Для `cycle_rotation_grid` и `combined_rotation_table` аналогичный составной date-expression pattern должен подтверждаться отдельно.

## Подтверждённые примеры

- `8 лекций: 07.04, 21.04–02.06`;
- `11 лекций: 07.04, 21.04–23.06`;
- `2 лекции: 10.04; 17.04`.

В первом примере structural weekday — вторник: одиночная дата `07.04` и семь вторников диапазона `21.04–02.06` дают ровно 8 лекций.
