# ОмГМУ — источники расписания

## Статус

Шаг 1 расширения на ОмГМУ завершён: определён основной официальный источник расписания и правила обнаружения новой редакции.

## Основной источник

Каноническая страница учебных занятий студентов высшего образования:

`https://omsk-osma.ru/studentam/raspisanie-zanyatiy`

Страница официального сайта ОмГМУ содержит расписания по факультетам и курсам. На текущей версии представлены лечебный, медико-профилактический, педиатрический, стоматологический, фармацевтический факультеты, отдельный блок «Лечебное дело для иностранных граждан» и программы магистратуры.

На странице указано, что расписание может изменяться. Поэтому источник должен мониториться как изменяемый, а не как одноразовый архив.

## Формат исходников

Подтверждённый основной формат — PDF. Контрольный официальный PDF для 1 курса программы «Лечебное дело для иностранных граждан»:

`https://omsk-osma.ru/files/r/UU/bilingva/2026/zan/1/1.1.pdf`

PDF содержит табличное расписание: группы по столбцам, дни недели по блокам строк, время, дисциплину, количество занятий, диапазон или перечень дат, лекции и часть локаций. Один файл может содержать русскую и английскую версии на разных страницах.

Формат отличается от XLSX КГМУ, поэтому ОмГМУ получает собственный PDF source adapter/parser. Канонический выход остаётся общим `schedule-batch/v1`.

## Определение новой версии

Источник считается изменившимся, если произошло хотя бы одно событие:

1. На канонической странице появился новый PDF URL для факультета, курса или потока.
2. URL не изменился, но изменился SHA-256 содержимого PDF.
3. Изменилась структура набора ссылок или подпись учебного периода так, что появился новый период или новая редакция.

URL нельзя считать идентификатором версии: университет может заменить файл по прежнему адресу. Authoritative source identity: `(source_page, pdf_url, sha256)`.

## Fail-closed инварианты watcher

- исчезновение ссылки не означает пустое расписание;
- временный HTTP 404/5xx или сетевой сбой не удаляет последнюю опубликованную версию;
- новая ссылка или новый SHA создают source candidate/review, но не публикуются автоматически;
- публикация разрешается только после разбора, canonical QA и review;
- неизвестная структура PDF не интерпретируется автоматически.

Защитная модель повторяет КГМУ, но source adapter ОмГМУ остаётся отдельным модулем.

## Дополнительные официальные источники

`https://omsk-osma.ru/studentam/raspisanie-ekzamenov` — отдельная официальная страница расписания экзаменов. На первом этапе не смешивается с основным source adapter учебных занятий и может быть подключена отдельно позже.

Страницы кафедр содержат локальные расписания, консультации и уточнения. Они не являются первичным источником общего группового календаря и могут использоваться только как дополнительные источники по отдельным правилам.

## Состояние 2026/27

На момент фиксации шага каноническая страница общего расписания содержит расписания весеннего семестра 2025/2026. Подтверждённый общий набор осеннего расписания 2026/2027 на этой странице пока не зафиксирован. Watcher должен обнаруживать новый учебный период по фактическому содержимому страницы и файлов без предположения о конкретном имени PDF.
