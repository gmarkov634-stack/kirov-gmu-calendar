# ОмГМУ — правило O69

## O69 — Продолжающая страница `combined_rotation_table` наследует схему колонок предыдущей страницы

Область применения: только `combined_rotation_table`.

Если следующая страница PDF является однозначным геометрическим продолжением той же таблицы, но не повторяет строку заголовков, она наследует подтверждённую `column_schema` предыдущей страницы.

Наследуются именно роли геометрических колонок: `discipline`, технические пустые/служебные области, `time`, `К.дн.` и конкретные групповые колонки. Отсутствие повторного номера группы на продолжающей странице само по себе не разрывает групповую принадлежность: содержимое в той же подтверждённой геометрической колонке относится к той же группе.

Наследование допустимо только если одновременно выполняются все условия:

- страница продолжает тот же `source_part` по O46;
- вертикальные границы и относительное расположение содержательных колонок согласуются с предыдущей страницей;
- на новой странице нет нового заголовка таблицы или иного явного маркера изменения схемы;
- геометрия не допускает альтернативного сопоставления ролей колонок.

O69 дополняет O43: O43 определяет семантику колонок по заголовкам и геометрии там, где схема явно задана, а O69 разрешает безопасно продолжить уже доказанную схему через page break без повторного header row.

Если на следующей странице изменились число, ширина или расположение значимых колонок, появился новый header/schema marker либо геометрическое продолжение неоднозначно, прежняя схема автоматически не переносится и соответствующий фрагмент получает `needs_review`. Само соседство страниц или отсутствие заголовков недостаточно для наследования.

## Подтверждённый пример

Русский `5.pdf`: на странице 3 таблица явно задаёт схему `Дисциплина | [техническая колонка] | Время | К.дн. | 585`. Страница 4 продолжает ту же таблицу без повторения заголовков; вертикальные границы колонок сохраняются.

Поэтому строки страницы 4, включая «Инфекционные болезни», «Поликлиническая терапия» и «Госпитальная терапия, эндокринология», продолжают использовать ту же групповую колонку 585, несмотря на отсутствие повторной надписи `585`.

Для `weekly_grid`, `course_lecture_list` и `cycle_rotation_grid` O69 автоматически не применяется без отдельного подтверждения.
