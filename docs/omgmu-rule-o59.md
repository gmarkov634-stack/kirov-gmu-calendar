# ОмГМУ — O59: source-local обозначения и сокращения

## Область применения

Только профиль `weekly_grid`.

## Правило

Если PDF содержит явный раздел `Обозначения и сокращения` / `Denotations and abbreviations`, однозначные пары `source alias → полное название` извлекаются как `source_aliases` соответствующего `source_part`.

Сокращённое обозначение дисциплины может быть заменено полным пользовательским названием только по явному соответствию из этой легенды. Исходное написание обязательно сохраняется в `raw_source/evidence`.

Запрещено:

- угадывать расшифровку по общему медицинскому словарю;
- использовать fuzzy-сопоставление;
- считать похожие сокращения эквивалентными;
- переносить расшифровку из другого PDF без отдельного подтверждения.

Структурный разбор ячейки выполняется до смыслового раскрытия сокращений. Символы `/`, `**` и другие служебные элементы сначала интерпретируются в структуре исходной записи по применимым правилам, включая O13, и только затем alias может быть заменён по легенде.

Русская и английская легенды относятся к своим языковым `source_part`. Если их соответствия конфликтуют и конфликт нельзя однозначно разрешить по O02/O15, результат получает `needs_review`.

Для других структурных профилей аналогичный механизм должен подтверждаться отдельно.

## Подтверждённые типовые соответствия текущих недельных PDF

- `B/chemistry → Bioorganic chemistry`
- `FOMT → Fundamentals of the medical terminology`
- `ОПЗ → Основы паразитарных заболеваний`
- `РП → Рациональное питание`
- `Russian → Foreign language (Russian language)`
- `Гистология, Э,Ц → Гистология, эмбриология, цитология`
