# ОмГМУ — O59: source-local обозначения и сокращения

## Область применения

Только профиль `weekly_grid`.

## Правило

Если русский `source_part` PDF содержит явный раздел `Обозначения и сокращения`, однозначные пары `source alias → полное название` извлекаются как `source_aliases` этого русского `source_part`.

Сокращённое обозначение дисциплины может быть заменено полным пользовательским названием только по явному соответствию из русской легенды. Исходное написание обязательно сохраняется в `raw_source/evidence`.

Запрещено:

- угадывать расшифровку по общему медицинскому словарю;
- использовать fuzzy-сопоставление;
- считать похожие сокращения эквивалентными;
- переносить расшифровку из другого PDF без отдельного подтверждения;
- использовать английскую легенду для дополнения или исправления русской части.

Структурный разбор ячейки выполняется до смыслового раскрытия сокращений. Символы `/`, `**` и другие служебные элементы сначала интерпретируются в структуре исходной записи по применимым правилам, включая O13, и только затем alias может быть заменён по легенде.

Английская легенда по O64 не участвует в production-разборе. Для других структурных профилей аналогичный механизм должен подтверждаться отдельно.

## Подтверждённые типовые соответствия русского source_part

- `ОМТ → Основы медицинской терминологии`
- `ОПЗ → Основы паразитарных заболеваний`
- `РП → Рациональное питание`
- `Гистология, Э,Ц → Гистология, эмбриология, цитология`
