# ОмГМУ — правило O55

## O55 — Иерархия временных ограничений источника

Если официальный PDF содержит несколько временных границ различной конкретности, для проверки конкретной учебной серии используется наиболее специфичная подтверждённая граница.

Приоритет:

1. явные даты самой серии;
2. локальный structural envelope (`N цикл` или иной однозначный блок);
3. специализированный `source_period` (`Аудиторные занятия` / `Auditorium classes`);
4. общий `source_period` (`Занятия` / `Classes`).

Более широкий период не расширяет более узкий и не создаёт дополнительные даты. Все такие границы используются для валидации, а не как самостоятельный источник событий.

Если явно указанная серия выходит за более узкую подтверждённую границу, парсер не удаляет её автоматически. Сначала проверяется наличие явного исключения или более конкретного указания в источнике. Если объяснения нет — серия получает `needs_review`.

O55 является общим правилом для всех текущих профилей ОмГМУ:

- `weekly_grid`;
- `course_lecture_list`;
- `cycle_rotation_grid`;
- `combined_rotation_table`.

## Подтверждённые примеры

### 5 курс, `5.pdf`

Общий период `Занятия: 06.04–08.08` шире специализированного периода `Аудиторные занятия: 06.04–07.08 — без субботы`. Поэтому обычные аудиторные серии валидируются по периоду до 07.08 и не расширяются автоматически на 08.08.

### 4 курс, `4zan.pdf`

Общий период занятий уступает более конкретным структурным envelope:

- `1 цикл: 07.05–31.07`;
- `2 цикл: 29.05–30.07`.

Внутри cycle-блока ещё более конкретный приоритет имеют явные диапазоны конкретной дисциплины и группы. Отдельные контрольные события за пределами structural envelope продолжают обрабатываться по O35/O37, если источник назначает их явно.
