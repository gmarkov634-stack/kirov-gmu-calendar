# ОмГМУ — правила O23–O24

- O23: номер цикла (`1 цикл`, `2 цикл`, `3 цикл` и т. п.) — структурный номер блока расписания, а не часть названия дисциплины. Он сохраняется только в техническом `source_cycle_no`/evidence и не выводится в название события.
- O24: если официальный файл лекций относится ко всему курсу/потоку и не содержит разделения по группам, его события применяются ко всем группам этого курса/потока, определённым по метаданным источника. Отсутствие номера группы в такой общей лекционной таблице не является неопределённостью.
