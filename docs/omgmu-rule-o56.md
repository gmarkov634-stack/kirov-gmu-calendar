# ОмГМУ — правило O56

## O56 — Отсутствие аудитории, клинической базы или преподавателя не делает занятие неполным

Для основных PDF расписания ОмГМУ обязательным ядром события являются данные, необходимые для однозначного определения занятия: группа/область групп, дисциплина, дата, время и подтверждённый тип занятия, когда он определяется источником.

`location`, аудитория, клиническая база и преподаватель являются необязательными enrichment-полями.

Если основной PDF их не содержит:

- событие создаётся без этих сведений;
- `needs_review` только из-за их отсутствия не выставляется;
- значения не угадываются по дисциплине, кафедре, соседним строкам или предыдущим занятиям.

Дополнение enrichment-полей разрешается только из отдельного официального источника, однозначно связанного с конкретной группой/серией/датой. Такой источник сохраняется отдельным `evidence/source_anchor`.

Название кафедры само по себе не считается автоматически местом проведения занятия.

Если дополнительный кафедральный источник противоречит основному PDF по дате, времени, дисциплине или иной существенной характеристике, он не должен молча изменять основное событие: конфликт переводится в `needs_review` и разрешается по правилам приоритета официальных источников.

## Область применения

O56 является общим правилом и применяется к:

- `weekly_grid`;
- `course_lecture_list`;
- `cycle_rotation_grid`;
- `combined_rotation_table`.

Правило применяется совместно с O17 и O28.
