# ОмГМУ — правило O62

## O62 — Набор групп недельной таблицы определяется буквально по заголовкам

В профиле `weekly_grid` множество групп конкретного `source_part` определяется только явно присутствующими заголовками групп и их геометрическими колонками.

Номера групп являются идентификаторами, а не числовым диапазоном. Пропуски в нумерации допустимы и не означают отсутствующие колонки, которые нужно восстановить.

Например, заголовки:

`385 | 386 | 387 | 388 | 389 | 393 | 394 | 395`

означают ровно эти восемь групп. Группы `390`, `391`, `392` из такого источника не создаются.

Для объединённой строки по O16 событие распространяется только на явно существующие групповые колонки, которые геометрически охватывает ячейка.

Запрещено:

- генерировать промежуточные номера групп;
- считать минимальный и максимальный номер границами диапазона;
- переносить отсутствующие группы из соседнего потока или другого PDF без отдельного официального подтверждения;
- создавать группу из числа, случайно встретившегося внутри текста занятия, даты, года, аудитории или другой служебной информации.

Если `source metadata` утверждает, что поток содержит дополнительные группы, но их колонок в конкретном `weekly_grid` нет, это не даёт права назначать им события этого файла. Для таких групп требуется собственный подтверждённый источник либо отдельное правило общей применимости.

Если заголовок групповой колонки повреждён и номер нельзя прочитать однозначно, соответствующая колонка получает `needs_review`; номер не угадывается по соседним значениям.

O62 применяется только к профилю `weekly_grid`. Для цикловых таблиц близкий принцип определения значимых колонок уже закреплён O43.

## Подтверждённый пример

В текущем `3.pdf` заголовки групп: `385 | 386 | 387 | 388 | 389 | 393 | 394 | 395`. Отсутствующие номера 390–392 не являются группами этого `source_part` и не восстанавливаются автоматически.
