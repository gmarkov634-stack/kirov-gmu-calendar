# ОмГМУ — правило O22

- O22: в цикловой таблице общие название дисциплины и время не означают автоматическую принадлежность события всем группам. Событие создаётся только для групп, в собственной колонке которых указана дата/диапазон либо ячейка однозначно охватывает группу по геометрии таблицы согласно O16. Пустая отдельная колонка группы означает отсутствие события для этой группы.
