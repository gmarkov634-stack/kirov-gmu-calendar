# ОмГМУ — правило O64

## O64 — Только русскоязычный source_part

В production-расписании ОмГМУ используется только русскоязычная логическая часть официального PDF.

Английский дубль может сохраняться как исходное доказательство и использоваться для классификации структуры всего PDF, но не создаёт события, не заполняет canonical-поля и не используется для дополнения, исправления или смысловой проверки русской части.

Перед специализированным разбором из полного layout-текста выделяется русский `source_part` по явному заголовку `РАСПИСАНИЕ ...` либо другому однозначному языковому маркеру, например `ru`. Страницы-продолжения наследуют язык по O46.

Если русскую часть невозможно выделить однозначно или она отсутствует, автоматический разбор прекращается с review-required результатом. Переход на английскую часть как запасной вариант запрещён.

O15 может исправлять доказуемую техническую опечатку только по данным русского `source_part` или другого официального русскоязычного источника.

### Область применения

O64 является общим правилом для `weekly_grid`, `course_lecture_list`, `cycle_rotation_grid` и `combined_rotation_table`.
