# ОмГМУ — правило O67

## O67 — Пробелы вокруг дефиса не определяют границу между `date_expression` и `location` в `course_lecture_list`

Область применения: только `course_lecture_list`.

После агрегации физических строк по O66 парсер сначала должен однозначно распознать полное выражение дат по O61/O27. Дефис или тире между двумя датами остаётся частью диапазона `dd.mm–dd.mm` независимо от пробелов. Только следующий дефис после уже завершённого `date_expression` может быть разделителем перед `location`.

Пробелы вокруг этого разделителя не обязательны. Поэтому варианты `04.05- БУЗОО...`, `07.04-28.04- БУЗОО...`, `08.04 - 06.05-БУЗОО...` и `09.04-30.04-БУЗОО...` структурно эквивалентны соответствующим вариантам с пробелами.

Сам дефис не доказывает наличие места проведения. Правый фрагмент должен однозначно соответствовать O58 как аудитория, корпус, клиническая база, организация или адрес. Если граница неоднозначна, `location` автоматически не заполняется; при однозначном обязательном ядре события занятие может остаться валидным по O56, иначе применяется `needs_review`. Исходная пунктуация сохраняется в `raw_source/evidence`.

## Подтверждённые примеры

Русский `source_part` текущего `4lek.pdf` содержит, в частности:

```text
04.05- БУЗОО«ОКБ»,ул.Березовая,3
07.04-28.04- БУЗОО «КРД № 6»,ул. Перелета,3
08.04 - 06.05-БУЗОО«ОКБ»,ул.Березовая,3
09.04-30.04-БУЗОО «ГДКБ № 3», инф. стационар, ул.19 Партсъезда,16
10.04; 17.04-БУЗОО«ОКБ»,ул.Березовая,3
```

В последнем примере `10.04; 17.04` является составным выражением дат, а дефис после `17.04` отделяет место проведения.

O67 применяется совместно с O58, O61 и O66. Для остальных source profiles автоматическая применимость этого строкового паттерна не предполагается.
