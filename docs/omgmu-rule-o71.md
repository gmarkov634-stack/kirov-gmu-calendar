# ОмГМУ — правило O71

## O71 — Похожее название дисциплины в другой серии не является основанием для автоматического смыслового объединения

Область применения: только `course_lecture_list`.

Название дисциплины каждой `source_series` сначала сохраняется буквально после допустимой типографической нормализации по O48.

Совпадение начала названия, общих слов, времени, места проведения или наличие более полного варианта названия в другой строке не разрешают автоматически:

- дописывать отсутствующие слова;
- раскрывать сокращение;
- считать две серии одной canonical discipline;
- объединять их счётчики или серии только по текстовому сходству.

Поэтому `Неврология, мед. генетика` не преобразуется автоматически в `Неврология, медицинская генетика, нейрохирургия` только потому, что более полная формулировка встречается в другой серии того же PDF.

Смысловое объединение или source alias допускается только при независимом однозначном подтверждении из официального русскоязычного источника, например явной source-local легенды либо другого документа ОмГМУ, который доказуемо устанавливает соответствие именно этих обозначений. Английская версия PDF не используется для такого дополнения или исправления по O64.

Если подтверждения нет, исходные названия сохраняются раздельно. Это само по себе не блокирует создание событий, если остальные обязательные поля однозначны.

## Подтверждённый пример

Русский `4lek.pdf` использует две разные формулировки:

```text
Неврология, медицинская генетика, нейрохирургия
```

и

```text
Неврология, мед. генетика
```

Они остаются раздельными source labels и не нормализуются друг к другу автоматически.

O71 дополняет O48: O48 ограничивает нормализацию внутри одной дисциплинарной записи, а O71 запрещает переносить смысл из другой серии только по сходству текста.
