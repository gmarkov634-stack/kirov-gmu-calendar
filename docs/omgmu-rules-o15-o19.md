# ОмГМУ — подтвержденные правила O15–O19

- O15: техническая опечатка в русскоязычном source_part исправляется автоматически только при однозначной независимой проверке внутри того же русского source_part либо другого официального русскоязычного источника; английский дубль по O64 не используется для исправления, иначе `needs_review`.
- O16: объединённая или визуально растянутая ячейка применяется ко всем группам, которые она однозначно охватывает. Принадлежность определяется по реальным геометрическим границам ячейки/объединённой области в PDF — линиям таблицы, границам колонок и фактическому span, — а не по горизонтальной позиции текста после `pdftotext -layout` или другого извлечения текста. Положение текста внутри merged cell само по себе не доказывает принадлежность одной конкретной группе. Сначала определяется набор геометрически охваченных групповых колонок, затем содержимое назначается всем этим группам. Если границы неоднозначны либо извлечённый layout-текст противоречит визуальной геометрии и конфликт нельзя разрешить по PDF, применяется `needs_review`. Подтверждённый пример `1.2.pdf`, понедельник: «Ин. язык (рус. язык)» охватывает 1107–1108, «Гистология, эмбриология, цитология» — 1109–1110, следующий «Ин. язык (рус. язык)» — 1111–1112; текстовое извлечение не должно сдвигать средний блок на 1108.
- O17: официальные страницы факультетов и кафедр ОмГМУ могут использоваться как дополнительные источники обнаружения и подготовки расписаний; перед production-публикацией обязательна сверка факультета, курса, периода и других официальных версий.
- O18: метка курса без фактической ссылки на файл не считается опубликованным расписанием и не запускает загрузку/парсинг.
- O19: только в `cycle_rotation_grid` несколько последовательных временных слотов одной дисциплины внутри одного однозначного циклового учебного блока могут объединяться в одно пользовательское событие от начала первого слота до конца последнего. Короткий внутриблочный перерыв отдельно не отражается; исходные source slots и evidence сохраняются. O19 не применяется автоматически к `weekly_grid`, `course_lecture_list` и `combined_rotation_table`. Подтверждённый пример `4zan.pdf`: `08:20–09:50` + `10:00–11:30` => `08:20–11:30`.
