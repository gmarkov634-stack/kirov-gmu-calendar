# ОмГМУ — подтвержденные правила O20–O21

- O20: в цикловом расписании диапазон дат разворачивается на учебные будние дни Пн–Пт с исключением официальных неучебных/праздничных дней. `К.дн.` используется как контрольное число; если количество получившихся дат не совпадает с `К.дн.`, результат требует `needs_review`.
- O21: если одна дисциплина явно разделена источником на лекции и цикловые занятия, это два независимых ряда событий. Пересечение дат не считается дубликатом; на одной дате могут существовать оба события.
