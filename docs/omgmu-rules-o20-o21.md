# ОмГМУ — подтвержденные правила O20–O21

- O20: в цикловом расписании диапазон дат разворачивается на учебные будние дни Пн–Пт с исключением официальных неучебных/праздничных дней. `К.дн.` используется как контроль числа уникальных учебно-контрольных дат блока: учитываются даты цикловых занятий и отдельно назначенного зачёта. Если зачёт проводится в отдельный день, эта дата увеличивает контрольное число на 1; если зачёт совпадает с днём цикла, дата считается один раз. Если итоговое число уникальных дат не совпадает с `К.дн.`, результат требует `needs_review`; подгонять даты автоматически запрещено.
- O21: если одна дисциплина явно разделена источником на лекции и цикловые занятия, это два независимых ряда событий. Пересечение дат не считается дубликатом; на одной дате могут существовать оба события.
